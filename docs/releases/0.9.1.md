# 0.9.1

Release date: 2026-11-19

A host no longer reads as full while it still has free slots. Occupancy probes
used the same exclusive lock as a running job, so several clients asking at
once counted each other as load and a job that could run waited for the queue
timeout instead. Probes now take a shared lock: they see the exclusive holders
and never block each other.

It changes no config key and no on-disk format.

## What changed

- `LockDir::occupied` takes `try_lock_shared`. Two probes on one host no
  longer conflict, so a free slot is reported as free under concurrent
  acquires.
- `Config::from_toml` now rejects what the code silently broke on: an unknown
  key (typos used to be ignored), two hosts with the same `name` (both counted
  as one worker), and `concurrency = 0` (a host that never accepts a job).
- `Config`, `Host` and `PathMap` use `deny_unknown_fields`. The shipped
  `config.example.toml` still loads unchanged.
- The journal replay stays off the dispatch path, so a large journal does not
  slow a transcode start.
- The SSH transport relays one merged stream instead of two, and capability
  matching no longer allocates per argument.
- The release binary is stripped of symbols.
- `cargo bench` runs the dispatch, journal, queue, progress and scheduler
  benchmarks. Continuous integration measures line coverage and fails under
  85 percent.

## What an operator sees

Nothing to change. A config that used to load with a typo now fails with the
key named, which is the point: the old behaviour dropped the setting and used
the default.

## Upgrading

```bash
rrffmpeg --version
```

Expect `rrffmpeg 0.9.1`. Nothing else is required.

Next:

```bash
curl -fsSL https://github.com/vasilvestre/rrffmpeg/releases/download/v0.9.1/rrffmpeg-x86_64-unknown-linux-musl.tar.gz \
  | tar -xz -C /tmp
sudo install -m755 /tmp/rrffmpeg-x86_64-unknown-linux-musl/rrffmpeg /usr/local/bin/ffmpeg
sudo ln -sf /usr/local/bin/ffmpeg /usr/local/bin/rrffmpeg
sudo ln -sf /usr/local/bin/ffmpeg /usr/local/bin/ffprobe
rrffmpeg capabilities worker
```
